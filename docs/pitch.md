## 1:20 – 1:50 · TECH

> **[Screen: code overview or architecture slide]**

"A few key decisions:

**Deterministic scoring** — rules, not randomness. Same wallet, same result, every time.

**State machine** — traits and mood update on events, not full re-renders.
Genesis once. Overlays always.

**Dual NFT model** — Soul Core is soulbound, non-transferable.
Snapshot Relic is the tradeable moment.

**LLM for expression only** — narrative, captions, roasts.
Never for classification. Classification is code.

**No raw conversation stored** — we track mutations, not messages.

Stack: Next.js, wagmi/viem, BNB Chain testnet,
Moralis data adapter, Anthropic Claude for captions."
