## Content Production (AI Pipeline)

### For text posts:
- Feed this strategy doc + archetype descriptions to Claude / GPT-4o
- Prompt: "Write a tweet about [archetype/feature]. Tone: degen, confident, slightly unhinged. Max 280 chars. No emoji spam, max 1-2."
- Generate 5 variants, pick the best

### For images:
- Character screenshots from the actual product (best authenticity)
- Archetype cards: use share card feature built into the app
- Before/after evolution: capture from Replay Mode
- Architecture diagrams: screenshot from README

### For video:
- Screen record Replay Mode flow (30-60 sec)
- Use ScreenStudio / OBS / QuickTime
- No editing needed — the product IS the content

## Anti-Patterns (Don't do this)

- Don't beg for votes in every single post — alternate with real content
- Don't tag all 9 handles in one tweet — rotate 2-4 max
- Don't use 10 hashtags — max 3 per tweet
- Don't post walls of text — keep it punchy
- Don't argue with other projects — support them, RT them
- Don't fake engagement — anti-bot mechanisms exist in voting
- Don't post about the tech without showing the product — screenshots > specs
